# 모션 명세 — 쇳물 방울

## 컨셉

에이전트는 **쇳물 한 방울**이다. 살아 있는 생물은 아니지만, 뜨거운 금속은 스스로 빛나고, 출렁이고, 식어 간다.
그래서 이 위젯의 모든 움직임은 하나의 규칙에서 나온다.

> **온도가 곧 상태다.** 색은 바꾸지 않는다. 데워지고 식을 뿐이다.

- 온도 `T`(0~1) 하나가 방울의 색, 빛 번짐, 표면 출렁임, 패널 윗선의 빛, 보내기 버튼 색을 모두 정한다.
- 색은 흑체복사 램프 하나만 쓴다: 식은 쇠(회색) → 검붉음 → 체리 → 주황 → 노랑 → 흰빛.
- 데워질 때는 빠르고(초당 2.6), 식을 때는 느리다(초당 0.42). 그래서 답이 끝난 뒤 몇 초에 걸쳐 천천히 식는 것이 보인다.
- 물리 규칙: 표면장력(눌리면 튕겨 돌아옴), 점성(스크롤하면 출렁임), 관성(커서 쪽으로 살짝 기울어짐).

## 공정 기록 띠

각 답변 위에 얇은 띠가 있다. 페이지 읽기·생각·웹 검색·답변 구간이 **실제로 걸린 시간만큼의 길이**로, 그 구간의 온도 색으로 칠해진다.
끝나면 아래에 `생각 1.2초 · 웹 검색 2회 · 전체 6.8초`처럼 요약이 남는다. 상태 문구는 한 번에 하나만 보이고 바뀔 때 위로 넘어간다.

## 움직임 줄이기 (prefers-reduced-motion)

출렁임·기울기·불티·열선·튕김을 끈다. 온도 변화(색)는 상태를 알려 주므로 남긴다. 패널은 원형으로 번지는 대신 짧게 나타나고 사라진다.

## 구현 메모

- 방울: SVG. 몸통 원 + 대류 덩어리 4개를 goo 필터(블러 + 알파 문턱)로 붙여 액체 윤곽을 만들고, 그 모양을 마스크로 써서 온도 그라데이션·대류 빛·산화 껍질(feTurbulence)·반사광을 그린다.
- 물리: requestAnimationFrame 하나에서 스프링(눌림·기울기·출렁임)과 온도 1차 지연을 계산한다. 대기 중에는 30fps로 줄인다.
- 불티·김: 필요할 때만 만드는 전체 화면 캔버스. 입자가 없으면 크기를 0으로 줄여 메모리를 돌려준다.
- 뜨거운 새 글자: 스트리밍 중인 마지막 문단만 매 프레임 다시 그리고, 도착한 지 0.9초 안 된 글자 조각에 나이별 그라데이션을 입힌다.
