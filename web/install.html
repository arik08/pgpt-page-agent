페이지 에이전트

지금 보고 있는 웹 페이지를 읽고 바로 답합니다. 필요하면 웹 검색으로 최신 정보도 찾아 줍니다. 확장 프로그램 설치 없이 북마크 하나로 씁니다.

설치

  1. 북마크바를 켭니다
    Chrome·Edge에서 Ctrl + Shift + B
  2. 아래 버튼을 북마크바로 끌어다 놓습니다
    페이지 에이전트
    끌어다 놓기가 안 되면 코드를 복사해 새 북마크의 URL 칸에 붙여 넣으세요.
  3. 아무 페이지에서나 북마크를 누릅니다
    오른쪽 아래에 쇳물 방울이 내려앉고 대화창이 열립니다. 다시 누르면 닫힙니다. 페이지를 새로 열면 한 번 더 눌러 주세요.
https 사이트에서 처음 쓸 때 Chrome이 “로컬 네트워크의 기기를 찾고 연결” 허용을 물을 수 있습니다. 허용을 누르세요. 보안 정책 때문에 페이지에 직접 붙지 못하는 사이트에서는 같은 대화창이 새 창으로 열립니다.

지금 해 보기

이 페이지 오른쪽 아래 방울을 눌러 보세요. 본문이 있는 페이지로 시험하려면 예시 페이지에서 북마크를 누르면 됩니다.

모델
{{MODEL}}

지금은 이 PC에서만 열려 있어 동료가 접속할 수 없습니다. 같은 망에 공개하려면 .env에 AGENT_HOST=0.0.0.0을 넣고 서버를 다시 실행하세요.

단축키

  • Enter 보내기 · Shift + Enter 줄바꿈
  • Esc 답변 중이면 멈추기, 아니면 닫기
  • 페이지에서 글을 드래그해 고른 뒤 물으면 그 부분을 중심으로 답합니다.
